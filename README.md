# 🎓 Universidad Europea Login (Python + Tkinter)

Aplicación de escritorio desarrollada en Python utilizando Tkinter que simula un sistema básico de inicio de sesión para usuarios de una universidad.

---

## 🚀 Características

- Interfaz gráfica con Tkinter
- Validación de usuarios (nombre, contraseña y cargo)
- Tabla de usuarios válidos
- Mensajes dinámicos en la interfaz
- Botones funcionales:
  - Limpiar formulario
  - Entrar (login)
  - Salir de la aplicación
- Logo personalizado (imagen o fallback gráfico)

---

## 🧑‍💻 Tecnologías utilizadas

- Python 3
- Tkinter (GUI)
- ttk (componentes modernos)
- OS y SYS (manejo de sistema)
